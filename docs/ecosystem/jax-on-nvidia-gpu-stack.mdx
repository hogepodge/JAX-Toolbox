<div className="eco-panel" id="proj-maxtext">

**MaxText**

A scalable, high-performance JAX LLM framework (GPT, Llama, Gemma, Mistral, Mixtral). NVIDIA actively tests and contributes to MaxText and publishes a tuned container, making it the reference pre-training framework for JAX on NVIDIA GPUs.

[Learn more →](../frameworks/maxtext/README.md)

</div>
<div className="eco-panel" id="proj-maxdiffusion">

**MaxDiffusion**

A scalable JAX framework for diffusion-model training, sharing MaxText's performance philosophy. Runs on NVIDIA GPUs through the same XLA/JAX stack.

[Learn more →](https://github.com/AI-Hypercomputer/maxdiffusion)

</div>
<div className="eco-panel" id="proj-axlearn">

**AXLearn**

Apple's deep-learning framework built on JAX and XLA for large-scale models such as the Fuji family. NVIDIA validates AXLearn on GPU clusters and publishes an `axlearn` container.

[Learn more →](../frameworks/axlearn/README.md)

</div>
<div className="eco-panel" id="proj-alphafold3">

**AlphaFold3**

DeepMind's protein-structure model. NVIDIA provides an optimized inference container (`ghcr.io/nvidia/jax:alphafold`) for running AlphaFold3 on GPUs.

[Learn more →](https://github.com/google-deepmind/alphafold3)

</div>
<div className="eco-panel" id="proj-nsight">

**Nsight Systems**

NVIDIA Nsight Systems (system-wide CPU+GPU+NVLink timeline) and Nsight Compute (per-kernel roofline, memory throughput, warp efficiency), bundled in the NGC JAX container for deep GPU-side profiling.

[Learn more →](https://developer.nvidia.com/nsight-systems)

</div>
<div className="eco-panel" id="proj-nsys-jax">

**nsys-jax**

A JAX-Toolbox wrapper around Nsight Systems that captures and post-processes profiles of JAX programs, aligning XLA/HLO with GPU timelines.

[Learn more →](../nsys-jax.md)

</div>
<div className="eco-panel" id="proj-xprof">

**XProf**

OpenXLA's profiler — trace viewer, HLO op profile, memory viewer, and roofline analysis. On NVIDIA GPUs it collects traces via CUPTI and shares the XLA HLO graph view; NVIDIA contributes to the GPU path.

[Learn more →](https://github.com/openxla/xprof)

</div>
<div className="eco-panel" id="proj-grain">

**Grain**

A deterministic, checkpointable input-data pipeline for JAX. Framework-independent and runs on NVIDIA GPUs.

[Learn more →](https://github.com/google/grain)

</div>
<div className="eco-panel" id="proj-optax">

**Optax**

A library of composable gradient-processing and optimization transforms for JAX, used by training frameworks across the ecosystem.

[Learn more →](https://github.com/google-deepmind/optax)

</div>
<div className="eco-panel" id="proj-orbax">

**Orbax**

Any-scale distributed checkpointing for JAX, shared across TPU and GPU workflows.

[Learn more →](https://github.com/google/orbax)

**Flax**

A flexible neural-network authoring library for JAX (the NNX API). Used across NVIDIA's NGC containers and Google's MaxText; NVIDIA contributes upstream.

[Learn more →](https://github.com/google/flax)

</div>
<div className="eco-panel" id="proj-pallas-mosaicgpu">

**Pallas / Mosaic GPU**

Pallas is JAX's kernel-authoring API; on NVIDIA GPUs it lowers primarily to the Mosaic GPU backend (Hopper+), exposing the GMEM to SMEM to registers pipeline, TMA async copies, and warp specialization. A Triton backend remains as an Ampere+ fallback.

[Learn more →](https://docs.jax.dev/en/latest/pallas/index.html)

<div className="eco-panel" id="proj-te">

**TransformerEngine**

NVIDIA's mixed-precision training library. The JAX extension delivers FP8, MXFP8, and NVFP4 training on Hopper and Blackwell Tensor Cores and ships inside NVIDIA's NGC JAX container, unlocking low-precision paths that reach deeper into NVIDIA silicon than framework-agnostic quantization.

[Learn more →](https://github.com/NVIDIA/TransformerEngine)

<div className="eco-panel" id="proj-cutlass">

**CUTLASS**

NVIDIA's open-source CUDA templates for high-performance GEMM and convolution — a building block for custom kernels and library backends on NVIDIA GPUs.

[Learn more →](https://github.com/NVIDIA/cutlass)

</div>
<div className="eco-panel" id="proj-tokamax">

**Tokamax**

A curated library of state-of-the-art custom kernels (attention and more) exposed through Pallas, with per-hardware autotuned implementations on NVIDIA GPUs.

[Learn more →](https://github.com/google/tokamax)

</div>
<div className="eco-panel" id="proj-flashinfer">

**FlashInfer**

A high-performance library of attention and LLM-serving kernels for NVIDIA GPUs (prefill/decode attention, paged KV cache), used to accelerate JAX/GPU inference paths.

[Learn more →](https://github.com/flashinfer-ai/flashinfer)

</div>
<div className="eco-panel" id="proj-mlir-trt">

**MLIR-TRT**

MLIR-TensorRT — an MLIR-based compiler path that lowers StableHLO to optimized TensorRT engines for NVIDIA inference.

[Learn more →](https://github.com/NVIDIA/TensorRT-Incubator)

</div>
<div className="eco-panel" id="proj-jax">

**JAX**

Accelerator-oriented array computation with composable transforms — `jit`, `grad`, `vmap`, `pmap`. Hardware-agnostic and the foundation of the whole stack; runs on NVIDIA GPUs through XLA's CUDA backend.

[Learn more →](https://github.com/jax-ml/jax)

</div>
<div className="eco-panel" id="proj-xla">

**XLA**

The shared JIT compiler behind JAX. Programs trace to StableHLO, which XLA:GPU lowers via LLVM NVPTX to PTX/SASS, calling cuBLAS and cuDNN as library ops. OpenXLA is co-developed by NVIDIA alongside Google and others.

[Learn more →](https://github.com/openxla/xla)

</div>
<div className="eco-panel" id="proj-pathways">

**Pathways**

Google's proprietary single-controller runtime for orchestrating large TPU pods. Shown for context — it is not part of the NVIDIA GPU path, where multi-node JAX uses HPC-X/OpenMPI, Ray, or SLURM.

</div>
<div className="eco-panel" id="proj-cupti">

**CUPTI**

The CUDA Profiling Tools Interface — the low-level API that profilers (including XProf's GPU path and nsys-jax) use to collect GPU traces and metrics.

[Learn more →](https://docs.nvidia.com/cupti/)

</div>
<div className="eco-panel" id="proj-cudnn">

**cuDNN**

NVIDIA's deep-learning primitive library, called by XLA:GPU for convolutions and attention. Provides fused FlashAttention and paged-attention kernels used under JAX.

[Learn more →](https://developer.nvidia.com/cudnn)

</div>
<div className="eco-panel" id="proj-cublas">

**cuBLAS / cuBLASLt**

NVIDIA's GEMM library (cuBLAS / cuBLASLt), invoked by XLA:GPU for matrix multiply — including FP8 and MXFP8 matmul on Hopper and Blackwell.

[Learn more →](https://developer.nvidia.com/cublas)

</div>
<div className="eco-panel" id="proj-nccl">

**NCCL**

The NVIDIA Collective Communications Library — topology-aware AllReduce, AllGather, and ReduceScatter across NVLink and InfiniBand. JAX/XLA drives multi-GPU and multi-node collectives through NCCL.

[Learn more →](https://developer.nvidia.com/nccl)

</div>
<div className="eco-panel" id="proj-nvshmem">

**NVSHMEM**

GPU-initiated symmetric memory for low-latency, fine-grained communication. Integrates with Mosaic GPU kernels to hide latency, complementing NCCL's bulk collectives.

[Learn more →](https://developer.nvidia.com/nvshmem)
