# Documentation assets

Brand assets and (optional) web fonts referenced by `fern/docs.yml`.

- `NVIDIA_light.svg` / `NVIDIA_dark.svg` — navbar logos (light/dark themes)
- `NVIDIA_symbol.svg` — favicon (NVIDIA eye symbol)

These are the official NVIDIA brand SVGs, sourced from the
[ai-dynamo/dynamo](https://github.com/ai-dynamo/dynamo/tree/main/docs/assets)
documentation, matching the reference layout this site is based on.

To use custom NVIDIA Sans / Roboto Mono fonts, drop the `.woff2` files in a
`fonts/` subdirectory and uncomment the `typography:` block in `fern/docs.yml`.
